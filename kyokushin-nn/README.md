# Киокусинкай Нижний Новгород

Evidence-first рекламно-информационный сайт о киокусинкай/синкёкусинкай в Нижнем Новгороде.

## Что это

Независимый проект, а не сайт конкретной федерации. Он сознательно разделяет разные нижегородские организации и не публикует неподтвержденные звания, телефоны, адреса или тренерские роли как факт.

## Запуск

```bash
npm start
```

Открыть `http://127.0.0.1:4177`.

Проверки:

```bash
npm run check
```

## Content Studio

`/studio` — встроенный редактор JSON-контента. Запись работает только при заданном `ADMIN_TOKEN`.

Он позволяет редактировать новости, медиа, профили, залы и источники, экспортировать JSON и загружать локальные изображения. Любая фотография должна получить `sourceUrl`, `credit`, `rightsStatus` и `rightsNote`.

## Персональные данные

Сбор лидов выключен по умолчанию (`ENABLE_LEADS=false`). Сервер не принимает заявки, пока явно не включен сбор и не задан `LEAD_CONTROLLER_NAME`.

## Верификация

- `verified` — подтверждено надежным источником;
- `verified_*` — подтверждено с оговоркой;
- `needs_confirmation` — данных недостаточно, сведения не додумываются.

Критически важно не смешивать две разные организации:
1. РОФСО «Нижегородская федерация Синкёкусинкай каратэ», ОГРН 1115200004985.
2. НРОО «Спортивная Федерация Киокусинкай», ОГРН 1075200008641.

## Медиа

`owned`, `permission_granted`, `embed_only`, `source_only`, `unknown` — обязательные статусы прав. Чужие фото не копируются в проект без подтвержденного разрешения.
