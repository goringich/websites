# СинКёкусинкай — набор в Нижегородской области

Рекламный recruitment-сайт Нижегородской федерации СинКёкусинкай каратэ: группы начальной подготовки от 5 лет, 18 залов, 11 инструкторов, Нижний Новгород и Дзержинск.

## Что умеет сайт

- поиск по школе, адресу и инструктору;
- фильтрация по городу и дню недели;
- расписание для каждого зала;
- прямой `tel:` контакт с инструктором;
- открытие адреса в Яндекс Картах;
- адаптивный интерфейс для телефона;
- SEO/JSON-LD и базовая accessibility-разметка;
- никаких внешних runtime-зависимостей и backend-точек отказа.

Если расписание не было предоставлено в исходных данных, сайт явно пишет «Расписание уточняйте у инструктора» и ничего не додумывает.

## Запуск

```bash
npm start
```

По умолчанию: `http://127.0.0.1:4177`.

## Проверка

```bash
npm run check
```

Проверка валидирует JavaScript, обязательные UI-точки, 18 залов и 11 контактных номеров.
