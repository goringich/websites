# Kyokushin NN — design audit 2026-08-24

Status: source-grounded audit. Exact browser screenshot capture is currently blocked by the execution environment (`ERR_BLOCKED_BY_ADMINISTRATOR` for local/file navigation), so this document is **not** a perceptual review pass. Explicit owner rejection remains the highest visual authority.

## Overall verdict

The current v2 is technically coherent and materially better than a default static page, but its art direction is still a recognizable generic athletic/agency landing-page pattern rather than a distinctive Shinkyokushinkai federation experience.

The central failure is not color or spacing. It is the **visual skeleton**:

`dark hero -> giant headline -> image card -> metrics strip -> section heading -> card grid -> trainer card grid -> filter panel -> cards -> dark steps -> giant CTA`.

Polishing that skeleton further would mostly make the same weak direction more expensive.

## 1. Brand distinctiveness — weak

Current identity is mainly communicated through:

- black / warm paper / red palette;
- one federation logo;
- one action image;
- the word Shinkyokushinkai;
- large athletic typography.

Those cues are not enough to make the layout unmistakably belong to this federation. Replace the logo/name with another combat sport and most of the page would still work unchanged.

The new direction needs a federation-specific visual grammar built from real dojo/action photography, competition/documentary sequencing, strict rules/grid structure and strong physical rhythm rather than generic gradient decoration.

## 2. Hero — competent but template-like

Strengths:

- clear headline;
- clear section CTA;
- strong factual proof (18 / 11 / 5+);
- real action photography.

Weaknesses:

- classic 2-column text + framed photo composition;
- oversized headline is doing nearly all the visual work;
- red radial glow and vertical English label are decorative rather than structurally meaningful;
- image behaves like a premium card instead of a cinematic/documentary field;
- pill-ish navigation and button language conflict with the harder sports/editorial ambition.

Target: full composition where type and image overlap/answer one another, with a more poster-like first screen and an explicit visual path into the page.

## 3. Typography — hierarchy exists, voice is generic

Current system relies on the generic UI sans stack plus Georgia italic accents. Large negative tracking simulates editorial aggression, but there is no distinctive type family or typographic grammar.

Problems:

- system/UI sans makes body and display language feel too product-interface-like;
- Georgia italic is a familiar marketing shortcut rather than a federation voice;
- repeated tiny uppercase labels create pseudo-premium texture but little meaning;
- many headings rely on similar scale/weight tricks, so the page loses surprise over time.

Target: Cyrillic-capable condensed/display voice with deliberate poster line breaks, paired with a calm reading face. Use scale variation and alignment changes rather than only bigger/bolder.

## 4. Photography — real assets, weak art direction

The project has good real federation imagery, but most of it is treated as gallery/card content.

Current problems:

- too many images are visually equal;
- card boundaries weaken the sense of physical space/action;
- photo sequencing does not create a clear narrative arc;
- trainer section visually collapses when a verified portrait is unavailable, because the fallback becomes a generic card rather than an intentional typographic poster.

Target:

- fewer larger photographic moments;
- one or two full-bleed action frames;
- documentary crop sequencing;
- typographic trainer posters as a deliberate state, not a placeholder apology;
- identity-safe verified portraits remain special without making the other trainers look incomplete.

## 5. Composition — too componentized

The page repeatedly uses contained rectangular modules. Even where border radii are reduced, the underlying component-card logic remains.

This makes the site feel assembled rather than art-directed.

Target composition should alternate:

- full-bleed image;
- narrow editorial text rail;
- oversized typographic poster;
- dense practical directory;
- large whitespace/paper pause;
- dark competition/action chapter.

The section shapes themselves should carry rhythm.

## 6. Trainer roster — data-rich, visually repetitive

Current roster is a 12-column card grid with featured larger cards for verified portraits. Functionally correct, but it reads like a team component from a design system.

Problems:

- repeated card anatomy;
- same action row everywhere;
- initials fallback looks like missing media;
- name scale does not create enough personality;
- verified portraits change card size but not the overall storytelling model.

Target: poster roster. Each trainer has a numbered editorial block; verified portraits become full-height photographic posters, non-photo trainers become intentional type/poster blocks with location/hall facts. The visual state must be equally designed in both cases.

## 7. Gallery / archive — good content, not enough drama

Real training and competition material is the strongest emotional asset but is placed after the hero as a mosaic and archive-card system.

Target: photography becomes a chapter, not a component. Use oversized crops, staggered baseline, split-screen sequences and one controlled horizontal/diagonal rhythm. Albums remain clear destinations but visually subordinate to the live/action story.

## 8. Sections / schedule — function is stronger than form

The hall finder is one of the strongest product features: real filters, exact URL state, direct phone and map actions. Its visual treatment should therefore be clearer, calmer and more editorial than the showcase sections.

Current weaknesses:

- large rounded filter container;
- instructor cards inside another directory hierarchy;
- strong dark headers on every instructor create repeated visual weight;
- the practical section feels like another component library rather than a designed catalogue.

Target: directory/catalog grammar with sticky or visually anchored filter rail, clear city/day chips without SaaS pill overload, compact instructor headings and strong address/schedule rows.

## 9. Navigation — over-designed in the wrong vocabulary

Rounded capsule navigation is coherent but belongs to contemporary product/SaaS UI more than to the desired sports editorial world.

Target: low-profile rule-based navigation, clear active state, strong logo lockup and direct `Найти зал` action. Mobile keeps the same mental model and one practical sticky action.

## 10. Motion — currently too generic

Current motion is primarily:

- IntersectionObserver reveal;
- `translateY + opacity`;
- hero load animation;
- subtle hover scale;
- page progress line.

That is polish, not motion direction.

Target motion grammar:

- entry: typography/image mask reveal with one decisive beat;
- scroll: low-amplitude image parallax and chapter emphasis;
- interaction: directional line/edge/image focus states;
- state change: filter/search transitions that preserve spatial continuity;
- reduced motion: opacity/state only, no parallax or large movement.

Do not add continuous particles, floating circles or decorative movement.

## 11. Color/material — usable but too dependent on red + gradients

Black, warm paper and federation red are appropriate. The weakness is how often subtle radial gradients/circles are asked to create sophistication.

Target: preserve the palette but get richness from photography, typography, hard rule geometry, print/paper texture and negative space. Red becomes a controlled signal rather than ambient decoration.

## 12. Mobile — responsive, not yet independently composed

Existing breakpoints collapse grids competently, but the visual model remains mostly a desktop design stacked vertically.

Target mobile work must decide per section:

- focal element;
- ordering;
- alternate type size/line breaks;
- sticky contact action;
- whether media scrolls horizontally or stacks;
- which decorative rules disappear;
- touch alternatives to hover/parallax.

## High-impact redesign order

1. Replace the hero + navigation skeleton.
2. Introduce a real typography system.
3. Turn the photo chapter into the main emotional proof.
4. Rebuild trainer roster as posters, not cards.
5. Rebuild the hall finder as an editorial directory.
6. Add one coherent native motion grammar.
7. Recompose mobile independently.
8. Only then tune micro-polish.

## What will not count as a redesign

- changing the shade of red;
- adding more gradients;
- increasing border radius;
- adding more hover scale;
- adding GSAP only to reproduce the current fade-up system;
- renaming the same layout `v3`;
- creating three palette variants of the same hero/cards.
